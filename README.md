# Rock Paper Scissors 🎮

A Rock Paper Scissors game built with Python and Tkinter. It includes a graphical user interface, custom images, sound effects, random computer choices, and score tracking.

## Features

- 🪨 Rock, 📄 Paper, and ✂️ Scissors choices
- 🖥️ Graphical user interface using Tkinter
- 🎨 Custom game images
- 🏆 Player and computer score tracking
- 🎲 Random computer choices
- 💬 Different messages for each game outcome
- ⏳ Short delay before revealing the result

## Technologies Used

- Python
- Tkinter
- Pillow (PIL)
- Emoji
- Random

## How to Run

1. Clone the repository:
`git clone https://github.com/bhavya-1407/rock-paper-scissors.git`

2. Open the project folder:
`cd rock-paper-scissors`

3. Install the required packages:
`python -m pip install Pillow emoji`

4. Run the game:
`python game.py`
